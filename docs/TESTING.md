# 测试说明

默认构建只编译、打包和签名；`--checks` 显式运行 PhotoSelectChecks。测试无需真实 RAW：ARW/JPG/XMP 合成字节用于文件操作与分组，不能据此证明真实照片解码质量。

检查覆盖：目录/排序、缓存、分组、SQLite、收藏保护、独立时间码目录、重复筛选归属、同名保护、移动/复制校验、撤销、空目录清理、外部新增内容保留、失败回滚、未完成日志阻断。

核心检查会创建 UUID 临时目录，并在结束时清理自己的测试目录；复制撤销经系统废纸篓，不清空废纸篓。程序异常退出可能留下测试目录供诊断。测试中的权限检查依赖普通用户身份。

`GUIValidation.swift` 是历史辅助工具，要求自行准备指定数量的 RAW 和额外格式/方向样例；仓库不包含私人样张，也不保证历史整套工具对应当前全部界面文案。它不是默认 CI，也不会被普通启动触发。当前 UI 改动应人工验证 Home、目录树、M/F/Z、确认/取消、保护和简短反馈。

本轮发布整理不重跑历史 RAW 性能基准、全量 GUI 或外盘故障测试。运行日志在本地 `.build/logs`（或 `--work` 指定目录）中，可包含本机路径，分享前脱敏。
